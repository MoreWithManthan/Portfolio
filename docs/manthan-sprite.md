# Manthan companion artwork

Generated using the built-in image-generation tool with the user-supplied ManthanPortfolioImage.png as identity reference. Original portrait remains unchanged in public/assets/manthan-pixel.png.

Specification: transparent 4×4 equal-cell pixel-art atlas, complete chibi human centered in each cell, black wavy hair, warm brown skin, smiling clean-shaven face, dark suit, white shirt and maroon lanyard. Row 1: four front walking frames. Row 2: four right-facing walking frames (mirrored in CSS for left). Row 3: four back walking frames. Row 4: idle, blink, wave, sleep. Opposing arms and legs alternate while walking. No grid or text. Keep identity, size, and foot baseline consistent. Generated canvas is 1254×1254; CSS scales it to 192×192 for 48px cells without modifying the original raster.

The public GitHub repository was checked at commit 22d78c827830c7800ee6283442b8a5985d18573e. It contains the original oneko cat atlas and animation but no Ram human sprite. The supplied screenshot depicts the newer ramx.in layout, which differs from that public source. This adaptation follows the supplied screenshot's compact profile, single reading column, navigation and simple rows, with Manthan’s factual portfolio sections substituted. No source-code identity with the newer unpublished layout is claimed.
